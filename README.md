# 🤖 Telegram-бот «Я — Лидер»

Бот-воронка + автовыдача доступа после оплаты. **Полностью бесплатно.**

## Что умеет

| Функция | Описание |
|---------|----------|
| **Сбор заявок** | Имя родителя → телефон → имя ребёнка → возраст. Всё сохраняется в SQLite. |
| **Квалификация** | По возрасту понимаем, подходит ли ребёнок (7–14 лет). |
| **Приём оплаты** | Пользователь жмёт «Я оплатил» → отправляет скриншот → админ получает уведомление. |
| **Автовыдача доступа** | Админ нажимает «Подтвердить» → бот генерирует одноразовую ссылку в закрытый канал и отправляет клиенту. |
| **База клиентов** | Все заявки и оплаты хранятся в `users.db` (SQLite). |
| **Статистика** | Команда `/stats` показывает количество заявок и непроверенных оплат. |

## 🚀 Быстрый старт (3 шага)

### Шаг 1. Создай бота в Telegram

1. Напиши [@BotFather](https://t.me/BotFather)
2. Отправь `/newbot`
3. Придумай название (например, «Я — Лидер | Курсы») и username (например, `ya_lider_courses_bot`)
4. **Скопируй токен** — он выглядит как `123456789:ABCdef...`

### Шаг 2. Узнай свой Telegram ID

1. Напиши [@userinfobot](https://t.me/userinfobot)
2. Он пришлет твой ID (например, `123456789`) — это `ADMIN_ID`

### Шаг 3. Подготовь закрытый канал/группу

1. Создай канал в Telegram (например, «Я — Лидер | Материалы»)
2. Сделай его **закрытым** (приватным)
3. Добавь бота администратором в канал:
   - Управление каналом → Администраторы → Добавить администратора
   - Найди своего бота
   - **Разреши:** «Добавление участников» и «Создание пригласительных ссылок»
4. Узнай `CHANNEL_ID`:
   - Перешли любое сообщение из канала в [@userinfobot](https://t.me/userinfobot)
   - Он покажет ID (начинается с `-100`, например `-1001234567890`)

## 💻 Запуск на компьютере (для теста)

```bash
# 1. Перейди в папку бота
cd tgbot

# 2. Установи зависимости
pip install -r requirements.txt

# 3. Создай файл .env и вставь свои данные
# Windows:
copy .env.example .env
# Затем открой .env в блокноте и вставь BOT_TOKEN, ADMIN_ID, CHANNEL_ID

# 4. Запусти
python bot.py
```

Бот начнёт работать. Проверь: напиши ему `/start`.

## 🌐 Бесплатный хостинг 24/7 (Render.com)

Чтобы бот работал круглосуточно без твоего компьютера:

### 1. Зарегистрируйся на [render.com](https://render.com)

### 2. Создай новый Web Service
- New → Web Service
- Connect GitHub (или используй Public Git repository)
- Если нет GitHub — просто загрузи файлы через Dashboard:
  - New → Blueprint (или Upload)

### 3. Настрой сервис
- **Name:** `ya-lider-bot`
- **Runtime:** Python 3
- **Build Command:** `pip install -r requirements.txt`
- **Start Command:** `python bot.py`
- **Plan:** Free

### 4. Добавь Environment Variables
В разделе **Environment** добавь:
- `BOT_TOKEN` = твой токен от BotFather
- `ADMIN_ID` = твой Telegram ID
- `CHANNEL_ID` = ID канала (с `-100`)

### 5. Deploy
Нажми **Create Web Service**. Через 2–3 минуты бот заработает.

> ⚠️ **Важно:** на бесплатном тарифе Render "засыпает" через 15 минут бездействия. Чтобы бот не засыпал — используй **UptimeRobot** (см. ниже).

---

## ⏰ Как не дать боту заснуть (UptimeRobot)

1. Зарегистрируйся на [uptimerobot.com](https://uptimerobot.com) (бесплатно)
2. Add New Monitor → Monitor Type: **HTTP(s)**
3. Friendly Name: `Ya Lider Bot Ping`
4. URL: `https://ya-lider-bot.onrender.com` (твой URL с Render)
5. Monitoring Interval: **5 minutes**
6. Save

Теперь UptimeRobot будет "пинговать" твой сервис каждые 5 минут, и он не уснёт.

> Альтернатива без UptimeRobot: настрой **Webhook** вместо polling. Это сложнее, но бот не засыпает. Напиши, если нужно — распишу.

## 🔧 Кастомизация

### Изменить текст сообщений
Открой `bot.py` и найди строки с `text = (`. Меняй текст прямо в коде.

### Изменить цену курса
В сообщении после заявки есть строка «Стоимость курса: уточняй у менеджера». Замени на свою цену.

### Добавить вопросы в воронку
В классе `LeadForm` добавь новое состояние, затем обработчик — по аналогии с `child_age`.

## 🆘 Если что-то не работает

| Проблема | Решение |
|----------|---------|
| Бот не отвечает | Проверь, что `BOT_TOKEN` правильный |
| «Ошибка! Проверь, что бот админ в канале» | Добавь бота админом в канал и дай права на ссылки |
| Ссылка не приходит клиенту | Проверь, что `CHANNEL_ID` начинается с `-100` |
| Бот на Render засыпает | Подключи UptimeRobot |
